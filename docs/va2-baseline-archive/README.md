# VA2 baseline archive (optional artifacts)

Use this folder for **Phase 1 baseline exports** that should travel with the repo or be attached to a release — for example:

- Exported **HTML** from Unlayer after `loadDesign` + `exportHtml`
- **Design JSON** snapshots of assembled starters
- **Screenshots** of Unlayer gallery reference templates used in comparisons
- **`SCORES.md`** — table of `accessibilityScore` + rubric totals per baseline run

## Git

Large binary or HTML snapshots may be excluded from git via `.gitignore` patterns if needed; keep at least methodology in [`../va2-pro-quality-baseline.md`](../va2-pro-quality-baseline.md).

- [ ] **Rubric** — Weights in §5 of [va2-pro-quality-baseline.md](../va2-pro-quality-baseline.md) reviewed by product + design.
- [ ] **Thresholds** — Ship (≥75) vs experimental (≥60) agreed.
- [ ] **External refs** — At least 5 Unlayer gallery URLs recorded (see baseline doc §8); optional screenshots in this folder.
- [ ] **Internal refs** — At least 3 manifest starters assembled without error (`npm test` covers transactional receipt).
- [ ] **Lucy samples** — Two strategist-generated manifests captured (staging/production) OR waiver documented.
- [ ] **Client smoke** — One exported HTML verified in Gmail + one Outlook variant.
- [ ] **Industry order** — §22 default order confirmed or revised in writing.
